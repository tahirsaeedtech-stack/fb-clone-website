# fb-clone-website

This project is a simple **Facebook clone website** that I created while learning and practicing **Git and GitHub**.

The main purpose of this project was to understand how Git works in a real development workflow, including creating a repository, tracking changes, making commits, working with branches, and pushing a project to GitHub.

## 📌 About the Project

This Facebook clone is a practice project inspired by the basic layout and design of Facebook. It was created as part of my journey to learn web development and version control.

While building this project, I practiced using Git commands and learned how to manage my project using GitHub.

## 🛠️ Technologies Used

- HTML
- CSS
- Git
- GitHub

## 🎯 What I Learned

Through this project, I practiced:

- Creating a Git repository
- Initializing Git with `git init`
- Checking repository status with `git status`
- Adding files with `git add`
- Creating commits with `git commit`
- Viewing commit history with `git log`
- Working with branches
- Renaming the default branch from `master` to `main`
- Connecting a local repository to GitHub
- Using SSH authentication with GitHub
- Pushing code to a remote repository
- Managing project files and changes with Git
